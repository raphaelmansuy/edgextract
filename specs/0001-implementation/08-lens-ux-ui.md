# 08 — Lens: UX / UI

**WHY.** People need to see what was accepted, what to review, and what was skipped. REQ-4.

CLI: print entities, relations, stats. Quiet skip if the model is missing, with the pull command.

HTML report (`edgextract report`, [09-lens-front-design.md](09-lens-front-design.md)): highlighted markdown, tables, review queue, legend, “gate fitted: false” until calibrate.

Messages in plain English: “Pick NOT_ENTITY if it is not a named thing”; “Thresholds belong in your code.”

Pronouns show as skipped, not as PERSON (EC-6). Truncated pairs increment a visible stat (EC-11).
